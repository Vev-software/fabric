## What changed

This PR adds a public Fabric discovery-enrollment contract for Atlas discovery bootstrap and
ingestion access.

- adds a new `Vev.Fabric.Contracts.Discovery` surface with:
  - enrollment lifecycle states, transitions and fail-static evaluation
  - lifecycle transition request/result contracts
  - discovery lifecycle event envelope
  - shared discovery audit action/resource vocabulary
- adds public reason codes for pending, suspended, revoked and expired discovery enrollments
- publishes JSON Schemas and conformance samples for the new discovery contracts
- mirrors the new surface into the TypeScript SDK
- documents the discovery enrollment boundary and its relation to entitlement and audit
- adds contract and state-machine tests plus schema-conformance coverage

## Why this changed

`atlas-enterprise#9` needs Fabric-owned seams for:

- tenant-bound machine-principal enrollment
- auditable credential activation/rotation/suspension/revocation
- explicit denied states that fail closed instead of degrading to product-local fallback

The existing `atlas.discovery.ingestion` capability was already seeded, but the public Fabric
surface did not yet define the lifecycle and event contracts needed around discovery bootstrap.

## User and developer impact

- Atlas Enterprise can now depend on a public Fabric contract for scanner enrollment instead of
  inventing a private bootstrap path.
- Discovery access can be denied with stable reason codes when enrollment is pending, suspended,
  revoked or credential-expired.
- Audit and lifecycle tooling get stable discovery-specific vocabulary without changing the shared
  Fabric audit envelope shape.
- SDK consumers on both .NET and TypeScript get the same public contract surface.
